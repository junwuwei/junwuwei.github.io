# 自用软件

 

  - Fongmi/TV
  
    >感谢Fongmi/TV作者提供了如此好用方便的软件.

    >在长期的使用过程中很多功能使用频率比较低 比如python js 迅雷等等
    
    >但这些功能导致软件包超过了30M
    
    >对软件大小有莫名的强迫症,对于用不到的功能统统移除掉
    
    >减少软件包的体积,理想的大小是10左右
    
    1. 移除 python js 支持
    2. 移除 thunder   支持
    3. 移除 tvbus force 
    4. 使用了gogole/media 版本,没有使用Fongmi/media fongmi分支 
    5. 支持smb://播放地址
    6. ok版的搜索特性合并过来
    7. 对源后面添加集数显示 
    8. 后续准备移除投屏功能
    9. 后续准备移除弹幕功能
    10. 软件更新地址修改为本仓库
